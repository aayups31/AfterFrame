# 09 — API Contracts

## Case creation

### `POST /api/cases`

Request:

```json
{
  "film": {
    "externalId": "movie-db-id",
    "title": "Black Hawk Down",
    "year": 2001,
    "version": {
      "label": "US theatrical",
      "runtimeMs": 8640000
    }
  },
  "curiosity": "I want to understand why everything went wrong.",
  "profileId": "default",
  "spoilerPolicy": "full"
}
```

Response:

```json
{
  "caseId": "case_123",
  "status": "intent_interpreting"
}
```

## Intent confirmation

### `POST /api/cases/:caseId/intent`

Response is typed:

```json
{
  "objective": "Trace how a short capture mission became an extended battle.",
  "scope": ["operational planning", "urban terrain", "command and communication"],
  "excludedForNow": ["film production"],
  "openingQuestion": "Which assumptions failed before the first helicopter was hit?"
}
```

## Start investigation

### `POST /api/cases/:caseId/start`

Returns a run ID and event stream URL.

## Event stream

### `GET /api/cases/:caseId/events`

Use Server-Sent Events or a comparable resumable stream.

Event types:

```text
case.intent.ready
research.status
source.discovered
source.locator.verified
evidence.ready
claim.updated
beat.ready
lead.ready
connection.suggested
research.degraded
research.completed
```

## Direction console

### `POST /api/cases/:caseId/directions`

Request:

```json
{
  "text": "Was the road network a larger factor than intelligence failure?",
  "anchor": {
    "beatId": "beat_18",
    "selectedText": "..."
  },
  "requestedAction": "auto"
}
```

Response:

```json
{
  "directionId": "dir_9",
  "directionType": "QUESTION",
  "branchAction": "create",
  "branchId": "branch_14",
  "acknowledgement": "That changes the trail. I’m following it.",
  "eventStreamUrl": "/api/cases/case_123/events"
}
```

The acknowledgement is not the result. Branch events update the main screen.

```json
{ "decision": "accepted", "userExplanation": "Both cases show unclear authority." }
```

## Open original

### `GET /api/evidence/:evidenceId/open`

Returns a fresh resolved target rather than trusting a stale client URL:

```json
{
  "url": "https://…",
  "displayLocator": "18:42–21:13",
  "status": "verified",
  "verifiedAt": "2026-08-04T18:00:00Z"
}
```

## Structured model output

All agent boundaries should use strict schemas. A beat schema should include:

- stable IDs;
- beat type;
- body;
- evidence IDs;
- claim IDs;
- visual directive enum;
- optional lead;
- pause behavior;
- confidence language;
- no raw URLs generated by the model.

Raw URLs must be attached by the resolver after validation.

## Close investigation

### `POST /api/cases/:caseId/close`

Request:

```json
{
  "mode": "visual_script",
  "includedBranchIds": ["branch_root", "branch_14"],
  "includeRejectedTheories": false,
  "preserveOpenQuestions": true,
  "generationLevel": "structure_and_draft"
}
```

Response returns a closure session, audit summary, and event stream for artifact blocks.

Additional events:

```text
direction.accepted
branch.created
branch.status
theory.assessed
closure.audit.ready
artifact.block.ready
artifact.completed
mission.digest.ready (future)
```
