# 11 — Build Roadmap

## Finals-safe mode

You have the itch now, but finals are the constraint. Channel it into a small artifact that preserves momentum without consuming the entire week.

### Session A — 90 minutes

- open the standalone prototype;
- adjust typography, rhythm, copy, and home transition;
- choose the final codename later;
- do not add backend work.

### Session B — 90 minutes

- run the Next.js starter;
- rebuild one home interaction yourself;
- commit screenshots and design decisions;
- stop.

### Capture-only backlog during finals

Keep one file of ideas. No feature implementation during study blocks.

## Phase 0 — Product lock

Deliverables:

- north-star statement;
- visual laws;
- exact MVP case;
- source rights boundary;
- one completed storyboard.

Exit test:

> A new collaborator can explain why this is not Perplexity with movie styling.

## Phase 1 — Premium mocked vertical slice

No real research backend.

Build:

- home portal;
- curiosity prompt;
- intent handoff;
- case masthead;
- 8–12 mocked beats;
- source inspector;
- direction console;
- mocked theory branch transition;
- note interaction;
- playlist control;
- world view;
- close-investigation review and visual-script preview.

Exit test:

> A person wants to keep scrolling even though the data is mocked.

## Phase 2 — Curated evidence engine

Use a hand-curated Black Hawk Down source pack.

Build:

- source records;
- exact locators;
- claim graph;
- beat schemas;
- streamed rendering;
- locator validation;
- answer-from-case evidence lookup mode.

Exit test:

> Every factual beat resolves to inspectable evidence.

## Phase 3 — Agentic source discovery

Build:

- intent interpreter;
- web-search source scout;
- resolver adapters;
- evidence extraction;
- claim verification;
- research run observability;
- degraded states.

Exit test:

> The system can create a credible new trail from a fresh curiosity without manual source entry.

## Phase 4 — Adaptive exploration

Build:

- live redirect;
- targeted follow-up research;
- narrative director;
- preference adaptation;
- quiet/proactive investigator-presence modes;
- trail insertion with stable sequence keys.

Exit test:

> Two users asking different questions about the same film experience visibly different journeys.

## Phase 5 — User-created worlds and closure

Build:

- persistent notes;
- graph and flow views;
- connection proposals;
- prior-case retrieval;
- portal links;
- close-investigation review;
- manual creation studio;
- sourced visual script and dossier;
- export.

Exit test:

> The final world visibly reflects what the user cared about, not merely what the agent found.

## Phase 6 — Multi-film expansion

Add three contrasting source patterns:

1. historical event — Black Hawk Down;
2. mythology/source adaptation — Troy or The Odyssey;
3. interpretation and production — Hereditary.

This forces the source taxonomy and agent behavior to generalize without pretending to support every film.

## Explicitly defer

- social feeds;
- public case marketplace;
- automated final video rendering;
- autonomous overnight research before foreground trust is proven;
- universal topic support;
- native mobile app;
- collaborative editing;
- poster licensing complexity;
- full copyrighted book ingestion;
- gamified completion percentages.

## Phase 7 — Autonomous missions

Add mission budgets, background workers, checkpoints, provisional branches, and return digests only after branch, evidence, and closure quality pass evaluation.
