# 38 — Launch and Pilot Checklist

## Curated alpha gate

### Product

- one film case has a complete beginning, branch, return, and close;
- curiosity intake can be corrected;
- user understands direction versus chat;
- notes and connections persist;
- no artificial completion percentage;
- playlist is optional and controllable;
- empty, degraded, and failure states are designed.

### Evidence

- all factual beats map to claims and evidence;
- each rendered locator was opened and manually spot-checked;
- source independence is recorded;
- version/cut identity is explicit;
- community interpretations are labeled;
- unsupported claims are removed or marked provisional;
- rights/access state is visible.

### Engineering

- typecheck, lint, tests, and production build pass;
- no client API keys;
- row-level security reviewed;
- idempotency and cancellation tested;
- telemetry redacts content;
- prompt-injection fixtures pass;
- error monitoring and cost tracing enabled;
- deletion removes derived data and jobs.

### Experience

- keyboard critical path passes;
- reduced-motion path passes;
- home media has low-data fallback;
- long-case scroll remains stable;
- first meaningful beat and branch latency measured;
- no source inspector feels like a card grid;
- audio never starts without permission.

## Creator pilot gate

- user can create a private project;
- permitted files can be imported with explicit retention;
- documentary or adaptation mode has been tested with a real task;
- dossier export preserves provenance;
- no generated artifact appears before explicit closure;
- user can correct evidence and see the correction propagate;
- privacy terms are understandable.

## Pilot packet

Provide:

- one-page product purpose;
- known limitations;
- how source verification works;
- how to report a bad locator;
- privacy and deletion behavior;
- feedback channel;
- expected pilot duration;
- permission to observe sessions separately from product consent.

## Post-pilot decision

Choose one:

- deepen consumer movie investigations;
- deepen documentary creator workflow;
- deepen adaptation/biopic workflow;
- pause business work and keep as portfolio/art product;
- stop because the core loop did not retain users.

Do not choose “build all segments.”
