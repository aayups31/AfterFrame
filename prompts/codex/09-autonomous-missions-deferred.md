# Codex Phase 7 — Autonomous Missions (Do Not Start Early)

Read `docs/21-autonomous-missions-later.md`.

Only implement this phase after foreground direction, evidence, theory, and closure evaluation thresholds are met.

- explicit mission authorization;
- durable background jobs;
- source, branch, time, and cost budgets;
- checkpoints and cancellation;
- provisional autonomous branches;
- no automatic user-belief acceptance;
- prioritized return digest;
- complete tool, source, cost, and prompt audit trail.
